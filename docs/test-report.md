1. Codex 自带 headless Chromium 可执行文件不可用；改用本机已安装 Chrome 的明确路径，桌面和手机浏览器操作均完成。

3. 测试缓存目录权限不稳定；使用项目内测试缓存和 `--basetemp` 完成最终运行。

补充说明：为不清空默认真实数据库，首页和账单列表的“无账单”分支本轮只做了前端条件、空状态文案和入口代码核对，没有删除全部真实数据后做运行态截图。这不是功能失败，也不改变已保存数据验收结论。
