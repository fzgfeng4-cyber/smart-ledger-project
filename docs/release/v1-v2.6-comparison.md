# Smart Ledger V1 与 V2.6 对比说明

## 一、版本状态

| 项目 | V1 | V2.6 |
| --- | --- | --- |
| 版本号 | `1.0.0` | `2.6.0` |
| Git 基线 | `v1.0.0-frozen` | `v2-development` 的 V2.6 冻结提交 |
| 发布状态 | 已冻结 | 已冻结 |
| 主要定位 | 本地单笔记账基础版本 | 本地离线增强版 |
| 后续开发 | 不再追加 V1 功能 | 新需求转入 V3 |

## 二、功能对比

| 功能 | V1 | V2.6 |
| --- | --- | --- |
| 一句话记账 | 支持 | 保留并继续支持 |
| 单笔确认、编辑 | 支持 | 保留并继续支持 |
| 批量记账 | 不支持 | 支持批量草稿和批量确认 |
| 首页搜索 | 不支持 | 支持组合搜索 |
| 最近账目 | 首页基础展示 | 调整到首页中间区域 |
| 分类统计 | 首页基础统计 | 支持分类金额和分类占比 |
| 月度预算 | 不支持 | 支持分类月度预算、剩余、超支和估算提示 |
| 微信账单导入 | 不支持 | 支持 CSV 导入和确认 |
| 支付宝账单导入 | 不支持 | 支持 CSV 导入和确认 |
| OCR 小票识别 | 不支持 | 支持本地识别并生成批量草稿 |
| AI 分类输入 | 不支持 | 支持本地确定性分类建议 |
| 备份恢复 | JSON 备份和恢复 | 保留并扩展兼容 V2 数据 |
| 删除和恢复 | 软删除、撤销恢复 | 保留并继续排除已删除记录 |

## 三、数据和安全对比

| 项目 | V1 | V2.6 |
| --- | --- | --- |
| 技术栈 | Flutter + Dart + SQLite | Flutter + Dart + SQLite |
| 金额存储 | `amount_cents` 整数分 | 保持 `amount_cents` 整数分 |
| 收支表达 | `type` 区分收入和支出 | 保持不变 |
| 原始文本 | 保存 `original_text` | 保持追溯，并覆盖导入/OCR/AI 草稿 |
| 删除策略 | `deleted_at` 软删除 | 保持不变 |
| 入库边界 | 用户确认后入库 | 所有来源统一用户确认后入库 |
| 网络依赖 | 无 | 无，Manifest 移除 `INTERNET` 和 `ACCESS_NETWORK_STATE` |
| 新增权限 | 无相机权限 | 增加 `CAMERA`，仅用于用户主动 OCR 拍照 |
| 数据上传 | 不上传 | OCR 和 AI 分类不上传云端 |

## 四、首页布局对比

| 区域 | V1 | V2.6 |
| --- | --- | --- |
| 顶部 | 标题和统计 | 沿用 V1 标题和统计，不改变 |
| 中部 | 其他首页内容 | 最近账目，方便打开后直接查看 |
| 底部 | 入口分布较分散 | 预算、搜索账目和快速记账集中在底部 |

## 六、兼容和冻结结论

V2.6 继续以 `v1.0.0-frozen` 为数据和业务基线，没有修改 V1 冻结标签。V1 的金额、收支、原始文本、软删除、用户确认后入库等核心规则在 V2.6 中继续有效。

V2.6 已完成本阶段功能和发布收尾，冻结后不再直接修改 V2.6。后续如果需要云同步、账号体系、自定义分类、更多平台导入或其他新功能，应在 V3 中重新进行需求、数据迁移、权限和测试设计。
