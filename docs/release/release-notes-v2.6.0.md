# Smart Ledger Android APP V2.6.0 更新说明

## 版本信息

- 版本号：`2.6.0`
- Android `versionCode`：`2`
- applicationId：`com.fzgfeng4.smartledger`
- 发布日期：2026-09-03
- 基线：V1 `v1.0.0-frozen`
- 状态：V2.6 已冻结，后续功能转入 V3

## 相比 V1 的主要更新

- 新增批量记账和批量确认，可一次整理多笔账目。
- 新增首页组合搜索，便于按金额、备注、原始文本和分类查找账目。
- 新增分类统计，查看指定月份的支出总额、收入总额和分类占比。
- 新增月度分类预算，显示已使用、剩余、超支和预计用完提示。
- 新增微信账单 CSV 导入。
- 新增支付宝账单 CSV 导入。
- 新增小票 OCR 识别，识别结果先生成批量草稿。
- 新增本地 AI 分类输入，使用本地确定性规则提供分类建议。
- 扩展 SQLite migration、备份恢复和软删除兼容，保留 V1 数据可读性。

## 首页调整

首页继续沿用 V1 顶部标题和统计区域，布局调整为：

1. 顶部：标题和统计。
2. 中间：最近账目。
3. 底部：预算、搜索账目和快速记账。

这样打开应用后可以更快看到最近账目，并从底部进入搜索和快速记账。

## 问题修复

- 修复 Release 构建缓存污染导致的 Material 小图标全部消失问题。
- 重新生成 Release APK，确认包含 `FontManifest.json` 和 `MaterialIcons-Regular.otf`。
- 修复导入保存失败时错误复用旧记账反馈的问题。
- 修复统计页首次加载与刷新竞态。

## 数据与隐私

- 金额继续使用整数分保存，未改变 V1 金额真相。
- 收入和支出继续使用独立的 `type` 字段表达。
- 删除继续使用软删除，统计和列表默认排除已删除记录。
- 导入、OCR、AI 分类和批量解析结果都必须经过用户确认后才写入正式账目。
- OCR 和分类处理保持本地运行，不上传用户图片或账目文字。
- 只增加相机权限用于用户主动发起的 OCR 拍照；未增加短信、通讯录、录音和定位权限。

## 已知限制

- V2.6 是离线优先的本地版本，不提供云同步、账号体系或云端 AI。
- OCR 结果受照片清晰度、排版和文字识别质量影响，仍需用户在确认页核对。
- 预计用完提示是基于当前数据的估算，不代表精确预测。
- 后续新增需求不在 V2.6 中直接追加，统一进入 V3 规划。
