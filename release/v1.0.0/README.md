## V1 功能边界

- 一句话记账、金额和收支识别、固定分类建议与用户确认。
- 本地 SQLite 账目保存，支持新增、编辑、软删除和撤销恢复。
- 账目列表、分页、搜索、本月统计和分类统计。
- 本地 JSON 备份与恢复。
- 离线运行，不依赖 Web 前端、Backend、登录或云端服务。

V2.6 和 V3.1 的新增功能不回写到这个 V1 冻结版本。后续版本请分别查看 `v2.6.0` 和 `v3.1.0` Release。

## 安装建议

如果设备已经安装同签名的 Smart Ledger，建议先备份账目，再使用覆盖安装。覆盖安装通常会保留本地应用数据；如果系统提示签名不一致，不要强行卸载旧应用，以免影响数据。
